# THE STALKERS: Paranoia - Original (Created by ВоваМания|YT)

Версия 1.0.1. Кооперативный хоррор для Minecraft Bedrock.

Файл для установки: `THE STALKERS - Paranoia - Original (Created by ВоваМания YT).mcaddon`.

В мире включите оба пака, **[BP]** и **[RP]**, и эксперимент Beta APIs.
Скрипты используют `@minecraft/server` 2.11.0 и `@minecraft/server-ui` 2.3.0.
Минимальная версия движка в манифесте: 1.21.50. Проверено на установленной игре 1.26.65.

Через 2 секунды после входа в чате должно появиться зелёное сообщение, что мод v1.0.1 загружен.
